# Contributing to ProFan

Thank you for helping improve ProFan.

1. Open an issue before changing hardware endpoints or safety behavior.
2. Fork the repository and create a focused branch.
3. Keep all user-visible text localized in English and Spanish.
4. Do not lower the manual minimum below 20% without hardware evidence and maintainer approval.
5. Build with `Build.ps1` and test Automatic restoration after every manual preset.
6. Submit a pull request describing hardware model, BIOS version, and test results.

Never include proprietary ASUS binaries, credentials, logs containing personal information, or third-party brand assets.
