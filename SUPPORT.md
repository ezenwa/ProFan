# Support

Use GitHub Issues for reproducible bugs and feature requests. Include:

- ProFan version and selected language.
- Exact ASUS model and BIOS version.
- Windows build and ASUS System Control Interface version.
- Whether ProArt Creator Hub or another ASUS utility was running.
- RPM readings, expected behavior, and safe reproduction steps.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
